# Chip's Challenge Bingo

Open `bingo.html` and select **Generate board**. Use **Copy invite link** to share the same set of challenges with other players; each player gets their own shuffled card.

Mark a square whenever its event happens during play. The center square is free, and completing any row, column, or diagonal scores a bingo. Progress is saved automatically in the browser.

- **Clear marks** resets progress without changing the card.
- **Reshuffle card** rearranges the current challenges and clears its marks.
- **New board** generates a new set of challenges.
