🎉 **Highlights**

- **ChipDX:** The project is now Chip's Challenge DX, with a refreshed browser interface and updated branding.
- **Linux AppImage:** A downloadable Linux build joins the Windows release. The x86_64 AppImage includes the game and bundled levelsets, targets glibc 2.31+, and keeps saves and configuration outside the image.
- **Custom levels in your browser:** Load additional levelsets, play levels from links, and share individual levels with a URL.
- **Replay playback:** Watch level replays directly in the browser.
- **Camera improvements:** New Fit zoom mode, smoother transitions between orthographic and perspective views, and improved camera framing and level-bound clamping.
- **Visual upgrade:** Optional CRT post-processing, a new tank model, improved pixel-art rendering and shadows, fixes for hidden-wall clipping, and camera shake for bomb explosions.
- **Desktop performance:** Configurable MaxFPS now limits rendering independently of the game simulation.
- **Gameplay fixes:** Red buttons can activate multiple clone machines; DAT import handles stacked blocks correctly; additional thin-wall combinations are supported.
- **Levelset updates:** More level corrections, replay validations, and record updates across the community packs.
- **Browser polish:** Automatic audio muting in the background, improved fullscreen controls, and a new shareable Chip's Challenge Bingo board for community play.

🛠️ **Editor improvements**

- **Browser editor added:** Create and edit levels directly in the web version.
- **Level metadata editing:** Edit the title, required chip count, time limit, hint, and author from the desktop editor.
- **Camera and layout tools:** Zoom controls and a background grid make navigating and editing levels easier.
